## Change Log
- **2026-11-04**:
  - Initialized repository, completed Agent Reach research on Wispr Flow alternatives.
  - Completed conceptual map and architectural blueprint in `trail_audit_and_architecture.md`.
  - Conducted UI interview: selected auto-popup bubble on focus, hybrid tap/push-to-talk, and Wispr Dark aesthetic.
  - Successfully configured standalone Android CLI SDK & Gradle 8.7.
  - Resolved WhatsApp/Telegram placeholder bug: sanitized field hints ("Message") preventing prepending ghost text.
  - Upgraded audio capture to VOICE_RECOGNITION DSP and 64kbps AAC for phonetic clarity.
  - Added Whisper prompt priming, deterministic temperature 0, and explicit language parameter ("it") to prevent spelling hallucinations like "a bici".
  - Eliminated prompt-leak hallucination: removed Whisper prompt parameter entirely to stop ghost prefixes like "Broadcast".
  - Upgraded translation engine to Wispr God Tier: Few-shot prompting, paragraph auto-splitting (\n\n), intelligent self-correction, currency/time normalization, and temperature 0.15 on Llama 3.3 70B.
  - Implemented Wispr Narrativo Engine: literary style prompts with dynamic dialog quotes («...»), story paragraphs (\n\n), expressive punctuation, and elevated temperature 0.35 on Llama 3.3 70B.
  - Added programmatic Kotlin post-processing: automated consecutive duplicate word removal (deduplication) and guaranteed uppercase capitalization after punctuation (. ! ? \n\n).
  - Added on-screen Toast alerts for LLM failure transparency.
  - Upgraded Wispr God-Tier Editor:
    - Integrated stream-of-consciousness real-world few-shot prompts with paragraph breaking (\n\n), quote formatting («...»), and filler removal (praticamente, diciamo, via discorrendo).
    - Enhanced Unicode regex sanitizer: deduplication across punctuation/commas (io, io -> Io), accented character support (però, però), and 2-word phrase deduplication.
    - Robust capitalization after periods, questions, exclamations, quotes, and newlines.
    - Typographic punctuation cleanup (no spaces before commas/periods, trimmed quote interiors).
  - Resolved Accessibility Service update & lifecycle disconnect:
    - Preserved `serviceInfo` XML configuration and capabilities (`canRetrieveWindowContent`) during runtime setup.
    - Removed forbidden `startService` call on AccessibilityService in MainActivity to prevent SecurityExceptions.
    - Added Lifecycle `ON_RESUME` re-check to instantly refresh permissions and restore the bubble when returning from Android settings.
    - Defaulted `showOnlyWhenFocused` to false so the bubble is persistently available on screen.
  - Eliminated Groq Rate Limit (HTTP 429) & Silent Fallback:
    - Reduced `max_tokens` from 2048 to 800, cutting TPM reservation by 60%.
    - Added automatic instant fallback to `llama-3.1-8b-instant` (30,000 TPM, <100ms) on Groq if 70B fails or is rate-limited.
    - Added high-priority Android Notification alerts so API or LLM errors are never silenced by background Toast restrictions.
    - Streamlined prompt tokens to ~450 with canonical few-shot based on real-world dictation ("MicFlow").
  - Fixed Silent Failure in LLM Pipeline:
    - Removed `PromptPreset.RAW` to eliminate the possibility of accidentally disabling AI formatting.
    - Fixed JSON parser bug: if choices were missing, it previously returned `Result.success(rawText)`, which tricked the pipeline into thinking the call succeeded and prevented fallback.
    - Removed `contextText` pollution from system prompt to stop confusing Llama with prior draft text.
    - Added explicit in-field diagnostic prefix on fallback so any API failure is immediately visible.
  - Punctuation Rhythm, Tech Brand Orthography, and Oral Starter Removal:
    - Analyzed user transcript tests from Groq and Gemini: both engines produced structured paragraphs with quotes and fast latency, but showed minor punctuation run-ons, coordinating conjunction starters ("E praticamente..."), and brand spelling errors ("Grok" vs "Groq", "Open AI" vs "OpenAI", "Flash Light" vs "Flash-Lite").
    - Updated `PromptPreset.NATURAL` system prompt with:
      - Rule 3 (Punteggiatura e Ritmo Fluido): forbids comma-splicing, mandates breaking oral run-ons with periods, colons (:), and dashes (—).
      - Rule 4 (Eliminazione Intercalari ed Esitazioni): strictly forbids starting sentences with coordinating conjunctions like "E praticamente", "E poi", "E quindi".
      - Rule 6 (Maiuscole e Brand Tecnologici): explicit dictionary for Groq, OpenAI, Gemini, Flash-Lite, Antigravity, OpenFlow, Wispr Flow.
      - Integrated user's real-world dictation as canonical few-shot training example.
    - Added deterministic post-processing in `AiPipelineClient.kt`:
      - Automatic brand normalization (Grok -> Groq, Open AI -> OpenAI, Flash Light -> Flash-Lite, antigravity -> Antigravity).
      - Regex stripping of oral sentence starters: `(?m)^[Ee]\s+praticamente\s*,?\s*` and `(?m)^[Pp]raticamente\s*,?\s*`.
    - Added unit tests in `PromptPresetTest.kt` verifying brand normalization and oral starter removal (all passed).
    - Output APK: `OpenFlow-debug.apk` (16.4 MB).
  - Handled Gemini HTTP 503 High Demand Spikes via Cascade:
    - Root cause: `gemini-3.8-flash` is experiencing temporary high demand (`HTTP 503 UNAVAILABLE`). The previous code exited early on non-404 status codes.
    - Updated `discoverActiveGeminiModels` to return the full ordered list of active models sorted by availability: prioritizing `3.5-flash-lite` (designed for massive continuous throughput without 503s), `3.5-flash`, `3.8-flash`, and `2.5-flash`.
    - Made the execution loop resilient: on any error (503, 429, 404, 500), it immediately cascades to the next candidate model in ~50ms.
    - Verified compilation & tests passed: new APK `OpenFlow-debug.apk` (16.4 MB).
  - Fixed Gemini Model Deprecation via ModelService.ListModels Dynamic Discovery:
    - Analyzed Gemini error: `gemini-1.5-flash is not found for API version v1beta`.
    - Added `discoverActiveGeminiModel`: automatically queries `https://generativelanguage.googleapis.com/v1beta/models?key=...` in 100ms, filters models supporting `generateContent`, and dynamically selects the user's provisioned Flash model (e.g. `gemini-3.8-flash`, `gemini-3.5-flash`, etc.).
    - Implemented in-memory caching for discovered Gemini and Groq models so subsequent audio runs have 0ms discovery overhead.
    - Optimized Groq latency: set `openai/gpt-oss-20b` as primary model (~250ms LPU response time vs ~2s on 120B), keeping `openai/gpt-oss-120b` as robust fallback.
    - Verified compilation & tests passed: new APK `OpenFlow-debug.apk` (16.4 MB).
  - Resolved Groq 404 & Decommissioned Models + Added Google Gemini Multimodal Provider:
    - Root cause discovery: Groq decommissioned both `llama-3.3-70b-versatile` and `llama-3.1-8b-instant`, causing HTTP 404 `model_not_found` on all LLM requests, forcing raw Whisper fallback.
    - Updated Groq default LLM model to `openai/gpt-oss-120b` with fallbacks to `openai/gpt-oss-20b` and `qwen/qwen3.8-27b`.
    - Added dynamic active model auto-discovery (`GET /v1/models`) on Groq to prevent future 404 errors if catalog changes.
    - Integrated Google Gemini (`gemini-2.5-flash` / `gemini-2.0-flash`) as a 100% free first-class provider using native multimodal audio (`audio/mp4` inline data) via Google AI Studio.
    - Updated UI in `MainActivity.kt`: added 3-way provider selector (Groq, Gemini, OpenAI) and updated preferences storage.
    - Verified compilation & tests passed: new APK `OpenFlow-debug.apk` (16.4 MB).
  - Compiled and verified debug APK: `OpenFlow-debug.apk` (16.4 MB) ready for deployment.
  - Implemented core Android architecture:
    - `data/PreferencesManager.kt`: EncryptedSharedPreferences, OpenAI & Groq endpoints, prompt presets.
    - `audio/AudioRecorderManager.kt`: High-efficiency AAC/M4A 16kHz audio capture with live amplitude metering.
    - `ai/AiPipelineClient.kt`: Two-stage pipeline (Whisper STT + LLM formatting/cleaner) with zero heavy SDKs.
    - `ui/FloatingBubbleOverlay.kt`: Floating hardware-accelerated canvas bubble with hybrid touch, dynamic waveform, and Wispr Dark styling.
    - `service/FlowAccessibilityService.kt`: Intercepts focused editable fields and injects polished text seamlessly via `ACTION_SET_TEXT`.
    - `ui/MainActivity.kt`: Jetpack Compose OLED Dark configuration and permissions onboarding.
    - `test/PromptPresetTest.kt`: Unit tests verifying prompt contract integrity.
